# LAB 05 — HOG-Based Industrial Defect Detection and Classification

## Objective

The objective of this laboratory is to develop an automated industrial visual inspection system for detecting and classifying steel surface defects.

The system follows the pipeline:

**Input Image → Preprocessing → HOG Feature Extraction → Machine Learning Classifier → Defect Classification → Quality-Control Decision**

The main techniques used are:

* Image preprocessing using OpenCV
* Histogram of Oriented Gradients (HOG)
* Support Vector Machine (SVM)
* Random Forest
* Confusion matrix
* Accuracy, Precision, Recall and F1-score
* HOG parameter analysis
* Robustness testing
* Industrial inspection decision module

---

## Dataset

The dataset used is the **NEU Steel Surface Defect Dataset**.

Dataset source:

**Kaggle:** `sovitrath/neu-steel-surface-defect-detect-trainvalid-split`

The dataset contains:

* **1,700 training images**
* **100 validation images**
* Image resolution: **200 × 200**
* Six steel surface defect classes

### Defect Classes

1. Crazing
2. Inclusion
3. Patches
4. Pitted Surface
5. Rolled-in Scale
6. Scratches

The dataset also contains XML annotation files describing the defects and their bounding boxes.

For this laboratory, the annotation class is used as the image-level classification label. Bounding-box information is not directly used for HOG classification.

# 3. Image Preprocessing

All images are resized to a common resolution:

```text
128 × 128
```

The preprocessing pipeline is:

```text
Original Image
      ↓
Resize to 128 × 128
      ↓
Convert to Grayscale
      ↓
Normalize Pixel Values
```

The grayscale image is normalized to the range:

```text
0 to 1
```

This reduces unnecessary color information and prepares the image for HOG feature extraction.

---

# 4. HOG Feature Extraction

Histogram of Oriented Gradients (HOG) is used to extract shape and edge information from steel surface images.

The baseline configuration uses:

```text
Cell size: 8 × 8
Orientations: 9
Cells per block: 2 × 2
Block normalization: L2-Hys
```

HOG focuses on local gradient directions rather than raw pixel values.

This is useful for steel defect detection because many defects appear as characteristic lines, edges, cracks, scratches, or texture changes.

The HOG representation is also visualized to understand the features extracted from the image.

---

# 11. Industrial Quality-Control Decision

A final inspection module is implemented to simulate an industrial quality-control system.

The system receives an image and performs:

```text
Input Product Image
        ↓
Preprocessing
        ↓
HOG Feature Extraction
        ↓
Trained SVM
        ↓
Defect Prediction
        ↓
Confidence
        ↓
Quality-Control Decision
```

Example output:

```text
==================================================
       PRODUCT INSPECTION RESULT
==================================================
Prediction: SCRATCHES
Confidence: XX.XX%
Action: REJECT PRODUCT
==================================================
```

Since the selected NEU dataset contains six defect classes and does not contain a genuine normal/non-defective class, every recognized class represents a defect.

Therefore:

```text
Known defect → REJECT PRODUCT
```

A true:

```text
Normal → ACCEPT PRODUCT
```

decision would require adding a genuine non-defective/normal class to the dataset.

# 14. Limitations

The main limitations of this implementation are:

1. The dataset contains defect classes but does not provide a genuine normal/non-defective class for binary quality-control classification.

2. HOG primarily captures gradient and shape information and may not represent complex texture information as effectively as deep-learning methods.

3. The validation dataset is relatively small compared with the training dataset.

4. Robustness testing uses artificially modified images rather than images collected from different real industrial environments.

5. The current implementation performs image-level classification and does not use the XML bounding boxes for precise defect localization.

6. Real industrial deployment would require testing under production-specific lighting, camera angles, vibration, blur, and other environmental conditions.

# 15. Conclusion

This laboratory demonstrates an automated steel surface defect classification system using Histogram of Oriented Gradients and machine-learning classifiers.

Images are first preprocessed and converted into grayscale representations. HOG is then used to extract gradient-based structural features. These features are classified using SVM and Random Forest models.

Different HOG cell sizes and orientation values are evaluated to identify a suitable feature configuration. The selected model is further tested against brightness changes, noise, rotation, and blur to evaluate robustness.

Finally, the trained model is integrated into an industrial inspection module that predicts the defect type, provides a confidence score, and produces a quality-control decision.

The project demonstrates how traditional computer vision and machine learning can be combined to create a lightweight industrial visual inspection system without relying on deep neural networks.
